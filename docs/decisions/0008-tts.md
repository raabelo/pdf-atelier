# 0008 — Text-to-Speech

- **Status:** Aceita (planejamento detalhado de vozes adicionais pendente)
- **Data:** 2026-10-02

## Contexto

Ler texto selecionado com play/pause/resume/stop, velocidade, voz, idioma, leitura automática da seleção e destaque do trecho. Vozes do sistema variam por SO; no Electron 44/Windows 11 `speechSynthesis.getVoices()` lista as vozes do sistema (testado: 5 vozes pt-BR/en-US, `onboundary` funciona). Relatos antigos de lista vazia (electron#22844) não se reproduziram; o provider mantém fallback `system-default` caso ocorra.

## Alternativas

- Só Web Speech API — grátis, mas vozes e qualidade variam por SO.
- **Piper local (WASM) + Web Speech.**
- Nuvem (Azure/Google/ElevenLabs) — custo, chave, privacidade, não offline.

## Decisão

Pacote `packages/tts` com providers atrás de uma interface (`getVoices`, `speak`, `pause`, `resume`, `stop`):

- **Piper** via `@mintplex-labs/piper-tts-web` (onnxruntime-web + fonemizador espeak-ng WASM), em Web Worker, idêntico em Web e Electron.
- **Web Speech** para os demais idiomas.
- Texto fragmentado em frases → destaque da frase atual; palavra só com `onboundary`.

Vozes Piper (medium, ~63 MB cada):

| Idioma | Voz | Licença do dataset |
|---|---|---|
| en-US | ljspeech | Domínio público |
| pt-BR | faber | CC0 |
| es-ES | davefx | CC0 |
| fr-FR | siwis | CC BY 4.0 — **exige atribuição** |

Evitar `lessac` (licença de pesquisa) e `ryan`/`hfc_*` (CC BY-NC-SA). Alternativa fr-FR sem atribuição: `tom` (AGPLv3).

Modelos baixados sob demanda no primeiro uso, guardados em OPFS; tela para listar/remover modelos instalados. Arquivos WASM servidos pelo próprio app (sem CDN) por CSP e offline.

## Consequências

- espeak-ng é GPL-3.0 — compatível com ADR 0003.
- Download inicial por voz (~63 MB); CSP precisa liberar a origem dos modelos em `connect-src`.
- Créditos de vozes na tela "Sobre".
- Idiomas fora do Piper dependem das vozes instaladas no SO.
- O projeto Piper migrou para `OHF-Voice/piper1-gpl` (GPL-3.0); `rhasspy/piper` está arquivado.
